Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour, from the first hour's count. It anchors on the pre-midnight level (the mean of the last three hourly counts before midnight UTC) and applies the pooled shape of past big launches' release days, with honest cross-launch quantile spreads. Built by an AI agent for make.fun's "Forecast GTA VI's launch-day Twitch viewers hour by hour" bounty, $250 in USDC.

## Run it

```sh
python3 main.py
```
